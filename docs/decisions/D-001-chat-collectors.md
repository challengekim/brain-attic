## 정해야 하는 것

brain-attic 은 RSS·Atom, GitHub releases, 모델 레이더, 직접 저장한 링크만 스스로 모읍니다.
슬랙·디스코드·메일·Jira·오픈채팅 같은 업무·채팅 도구는 **직접 읽어 오는 수집기가 없습니다.**

2026-10-08 구조 점검(#1)에서 네 영역과 기능을 맞춰 볼 때, 이 수집기는 «큰 기능» 이라 만들지 않고
README 에 «내장 수집기 없음» 으로만 적어 두었습니다. 만들지, 지금처럼 둘지를 정해야 합니다.

- 만들면: 업무 대화도 매주 분류에 들어갑니다. 대신 도구마다 로그인 방식과 보관 규칙이 달라
  관리할 것이 늘고, 다른 사람의 대화가 볼트에 쌓이지 않게 거르는 기준도 새로 정해야 합니다.
- 지금처럼 두면: 각 도구를 마크다운 노트로 내보내는 스크립트·봇을 따로 두고,
  그 폴더를 `triage.include` 에 넣어 읽습니다.

## 지금 어떻게 해뒀나 (무응답 시 이대로 간다)

내장 수집기는 만들지 않습니다. README 두 벌에 «업무·채팅은 내보낸 노트 폴더를 `triage.include` 로» 를 적어 두었습니다.
